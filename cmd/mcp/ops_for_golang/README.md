# Ops for Golang

Provides Go development helpers for test coverage, coverage reports, and `go run` execution.

## Installation

```json
{
  "mcpServers": {
    "ops_for_golang": {
      "command": "/home/user/devbox/pkg/bin/mcp/linux_amd64/devbox-mcp-tools",
      "args": [
        "ops_for_golang"
      ],
      "disabled": false,
      "autoApprove": []
    }
  }
}
```
