# Timezone

Provides timezone utilities to get current time, convert timezones, and list available timezones.

## Installation

```json
{
  "mcpServers": {
    "get-current-timezone": {
      "command": "/home/user/devbox/pkg/bin/mcp/linux_amd64/devbox-mcp-tools",
      "args": [
        "timezone"
      ],
      "disabled": false,
      "autoApprove": []
    }
  }
}
```
