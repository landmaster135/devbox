# OpenWeather Map

Provides weather forecast retrieval for a specified city using OpenWeather API.

## Installation

```json
{
  "mcpServers": {
    "open_weather_map": {
      "command": "/home/user/devbox/pkg/bin/mcp/linux_amd64/devbox-mcp-tools",
      "args": [
        "open_weather_map"
      ],
      "env": {
        "OPENWEATHER_API_KEY": "YOUR_VALUE"
      },
      "disabled": false,
      "autoApprove": []
    }
  }
}
```
