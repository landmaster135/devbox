# Google Drive

Provides Google Drive file access and content retrieval tools.

## Installation

```json
{
  "mcpServers": {
    "google_drive": {
      "command": "/home/user/devbox/pkg/bin/mcp/linux_amd64/devbox-mcp-tools",
      "args": [
        "gdrive"
      ],
      "env": {
        "GDRIVE_CREDENTIALS_PATH": "YOUR_PATH"
      },
      "disabled": false,
      "autoApprove": []
    }
  }
}
```
