# GitHub

Provides GitHub repository, issue, pull request, and search operations.

## Installation

```json
{
  "mcpServers": {
    "github": {
      "command": "/home/user/devbox/pkg/bin/mcp/linux_amd64/devbox-mcp-tools",
      "args": [
        "github"
      ],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "YOUR_GITHUB_PAT"
      },
      "disabled": false,
      "autoApprove": []
    }
  }
}
```
