# Datetime Calculator

Provides datetime calculation, time value extraction, and unit-converted summation tools.

## Installation

```json
{
  "mcpServers": {
    "datetime_calculator": {
      "command": "/home/user/devbox/pkg/bin/mcp/linux_amd64/devbox-mcp-tools",
      "args": [
        "datetime_calc"
      ],
      "disabled": false,
      "autoApprove": []
    }
  }
}
```
