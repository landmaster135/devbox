# Brave Search

Provides Brave Web Search and Brave Local Search tools.

## Installation

```json
{
  "mcpServers": {
    "brave_web_search": {
      "command": "/home/user/devbox/pkg/bin/mcp/linux_amd64/devbox-mcp-tools",
      "args": [
        "brave_web_search"
      ],
      "env": {
        "BRAVE_API_KEY": "YOUR_BRAVE_API_KEY"
      },
      "disabled": false,
      "autoApprove": [
        "brave_web_search"
      ]
    }
  }
}
```
