# Git Diff Recorder

Provides a tool to retrieve Git diff output from a target repository.

## Installation

```json
{
  "mcpServers": {
    "git_commit_message_generator": {
      "command": "/home/user/devbox/pkg/bin/mcp/linux_amd64/devbox-mcp-tools",
      "args": [
        "git_diff_recorder"
      ],
      "disabled": false,
      "autoApprove": []
    }
  }
}
```
