# HTTP Request

Provides a tool to make HTTP requests to external APIs.

## Installation

```json
{
  "mcpServers": {
    "http_request": {
      "command": "/home/user/devbox/pkg/bin/mcp/linux_amd64/devbox-mcp-tools",
      "args": [
        "http_request"
      ],
      "disabled": false,
      "autoApprove": []
    }
  }
}
```
