# EverArt

Generates images via EverArt models and returns links to view generated images.

## Installation

```json
{
  "mcpServers": {
    "everart": {
      "command": "/home/user/devbox/pkg/bin/mcp/linux_amd64/devbox-mcp-tools",
      "args": [
        "everart"
      ],
      "env": {
        "EVERART_API_KEY": "YOUR_KEY"
      },
      "disabled": false,
      "autoApprove": []
    }
  }
}
```
