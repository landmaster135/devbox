# Git Commit History Retriever

Retrieves Git commit history, with optional detailed commit metadata.

## Installation

```json
{
  "mcpServers": {
    "git_commit_history_retriever": {
      "command": "/home/user/devbox/pkg/bin/mcp/linux_amd64/devbox-mcp-tools",
      "args": [
        "git_commit_history_retriever"
      ],
      "disabled": false,
      "autoApprove": []
    }
  }
}
```
