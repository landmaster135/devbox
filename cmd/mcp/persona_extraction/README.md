# Persona Extraction

Extracts and summarizes structured persona information for characters.

## Installation

```json
{
  "mcpServers": {
    "persona_extraction": {
      "command": "/home/user/devbox/pkg/bin/mcp/linux_amd64/devbox-mcp-tools",
      "args": [
        "persona_extraction"
      ],
      "disabled": false,
      "autoApprove": []
    }
  }
}
```
