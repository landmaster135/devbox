# Context7

Searches Context7 libraries and fetches documentation by Context7-compatible library ID.

## Installation

```json
{
  "mcpServers": {
    "context7": {
      "command": "/home/user/devbox/pkg/bin/mcp/linux_amd64/devbox-mcp-tools",
      "args": [
        "context7"
      ],
      "disabled": false,
      "autoApprove": []
    }
  }
}
```
