# DuckDuckGo Search

Provides DuckDuckGo web search and instant answer tools.

## Installation

```json
{
  "mcpServers": {
    "duckduckgo_instant_search": {
      "command": "/home/user/devbox/pkg/bin/mcp/linux_amd64/devbox-mcp-tools",
      "args": [
        "duckduckgo_search"
      ],
      "disabled": true,
      "autoApprove": []
    }
  }
}
```
