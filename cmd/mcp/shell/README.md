# Shell

Provides a shell execution tool compatible with Codex CLI shell-style command execution.

## Installation

```json
{
  "mcpServers": {
    "shell": {
      "command": "/home/user/devbox/pkg/bin/mcp/linux_amd64/devbox-mcp-tools",
      "args": [
        "shell"
      ],
      "disabled": false,
      "autoApprove": []
    }
  }
}
```
