# YouTube Transcript

Extracts transcript text from a YouTube video URL or ID.

## Installation

```json
{
  "mcpServers": {
    "get_youtube_transcript": {
      "command": "/home/user/devbox/pkg/bin/mcp/linux_amd64/devbox-mcp-tools",
      "args": [
        "youtube_transcript"
      ],
      "disabled": false,
      "autoApprove": []
    }
  }
}
```
