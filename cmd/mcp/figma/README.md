# Figma

Provides tools to inspect Figma node data and download node images.

## Installation

```json
{
  "mcpServers": {
    "figma": {
      "command": "/home/user/devbox/pkg/bin/mcp/linux_amd64/devbox-mcp-tools",
      "args": [
        "figma"
      ],
      "env": {
        "FIGMA_API_KEY": "YOUR_KEY"
      },
      "disabled": false,
      "autoApprove": []
    }
  }
}
```
