# Sequential Thinking

Provides a structured sequential-thinking tool for dynamic, revisable problem solving.

## Installation

```json
{
  "mcpServers": {
    "sequentialthinking": {
      "command": "/home/user/devbox/pkg/bin/mcp/linux_amd64/devbox-mcp-tools",
      "args": [
        "sequentialthinking"
      ],
      "disabled": false,
      "autoApprove": []
    }
  }
}
```
