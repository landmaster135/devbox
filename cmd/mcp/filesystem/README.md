# Filesystem

Provides filesystem read, write, list, search, move, and metadata operations within allowed directories.

## Installation

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "/home/user/devbox/pkg/bin/mcp/linux_amd64/devbox-mcp-tools",
      "args": [
        "filesystem"
      ],
      "disabled": false,
      "autoApprove": []
    }
  }
}
```
