# Plan

Provides a structured planning helper tool to update multi-step plans.

## Installation

```json
{
  "mcpServers": {
    "plan": {
      "command": "/home/user/devbox/pkg/bin/mcp/linux_amd64/devbox-mcp-tools",
      "args": [
        "plan"
      ],
      "disabled": false,
      "autoApprove": []
    }
  }
}
```
