# PDF Merger ツール使用方法

## 概要

PDF Mergerは、複数のJPG画像ファイルを1つのPDFファイルにマージするためのコマンドラインツールです。

## インストール

ビルドスクリプトを使用してツールをビルドします：

```bash
cd devbox
./scripts/build_pdf_merger.sh
```

ビルドが成功すると、以下の場所に実行ファイルが生成されます：

- Linux用: `pkg/bin/linux_amd64/pdf-merger`
- Windows用: `pkg/bin/win_amd64/pdf-merger.exe`

## 基本的な使い方

JPG画像ファイルをPDFにマージするには、以下のコマンドを使用します：

```bash
./pdf-merger -dir <画像フォルダパス> [-out <出力PDFファイルパス>]
```

例：

```bash
./pdf-merger -dir ./images
```

このコマンドは、`./images`ディレクトリ内のJPG画像ファイルを収集し、`./images/images.pdf`という名前のPDFファイルにマージします。

```bash
./pdf-merger -dir ./images -out ./output.pdf
```

このコマンドは、`./images`ディレクトリ内のJPG画像ファイルを収集し、`./output.pdf`という名前のPDFファイルにマージします。

- 出力ファイル名が指定されていない場合は、ディレクトリ名に基づいて自動的に生成されます（例：`<ディレクトリ名>.pdf`）。
- 画像ファイルはアルファベット順にソートされてPDFに配置されます。
- 現在のバージョンでは、JPG形式（`.jpg`拡張子）の画像ファイルのみがサポートされています。

## オプション

| オプション | 説明 |
|------------|------|
| `-dir` | 画像を検索するフォルダー（デフォルト: カレントディレクトリ） |
| `-out` | 出力PDFファイル名（デフォルト: `<ディレクトリ名>.pdf`） |

## エラーメッセージ

以下のような場合にエラーメッセージが表示されます：

- 指定されたディレクトリが存在しない場合
- 指定されたディレクトリにJPG画像ファイルが見つからない場合
- PDFの生成に失敗した場合

## 使用例

### カレントディレクトリの画像からPDFを生成

```bash
./pdf-merger
```

### 特定のディレクトリの画像からPDFを生成

```bash
./pdf-merger -dir ./vacation_photos
```

### カスタム出力ファイル名でPDFを生成

```bash
./pdf-merger -dir ./vacation_photos -out ./vacation_album.pdf
```

## 注意事項

- 現在のバージョンでは、JPG形式（`.jpg`拡張子）の画像ファイルのみがサポートされています。
- 画像ファイルはアルファベット順にソートされてPDFに配置されます。
- 出力PDFファイルは、既存のファイルがある場合は上書きされます。
- 大量の画像ファイルや高解像度の画像ファイルを処理する場合は、メモリ使用量に注意してください。
