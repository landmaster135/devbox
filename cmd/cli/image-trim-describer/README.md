# image-trim-describer

画像のトリミング座標を視覚的に選択し、トリミング処理を行うためのツールです。

## 概要

このツールは、指定されたディレクトリ内の画像ファイルを一覧表示し、ブラウザベースのインターフェースを通じて画像のトリミング座標を視覚的に選択できるようにします。選択された座標に基づいて、画像のトリミング処理を実行します。

## 機能

- 指定されたディレクトリから画像ファイル（JPG、JPEG、PNG）を自動検出
- ブラウザベースのインターフェースで画像のトリミング座標を視覚的に選択
- トリミング処理の実行と結果の保存
- 元画像のアーカイブ（オプション）

## 使用方法

```bash
image-trim-describer [オプション]
```

### オプション

- `-src <ディレクトリ>`: 画像ファイルのディレクトリ（デフォルト: カレントディレクトリ）
- `-out <ディレクトリ>`: 出力先ディレクトリ（デフォルト: 入力ディレクトリと同じ）
- `-arc <ディレクトリ>`: アーカイブ先ディレクトリ（デフォルト: ./5_original_files）
- `-suffix <サフィックス>`: 出力ファイル名に付加するサフィックス（デフォルト: trimmed）
- `-move`: 元ファイルを移動する（コピーではなく）

### 使用例

```bash
# カレントディレクトリの画像ファイルを処理
image-trim-describer

# 指定したディレクトリの画像ファイルを処理
image-trim-describer -src ./images

# 出力先ディレクトリを指定
image-trim-describer -src ./images -out ./output

# アーカイブ先ディレクトリを指定し、元ファイルを移動
image-trim-describer -src ./images -arc ./archive -move
```

## 動作の流れ

1. コマンドを実行すると、指定されたディレクトリから画像ファイルを検索します
2. `image_trimmer.html` ファイルが生成され、自動的にデフォルトブラウザで開かれます
3. ブラウザ上で画像を選択し、トリミング座標を指定します
4. 「トリミング実行」ボタンをクリックすると、指定された座標に基づいて画像がトリミングされます
5. トリミングされた画像は指定された出力先ディレクトリに保存されます
6. 元の画像は、設定に応じてアーカイブディレクトリにコピーまたは移動されます
7. コマンドラインでEnterキーを押すとプログラムが終了します（HTMLファイルは削除されません）

## ビルド方法

リポジトリのルートディレクトリで以下のコマンドを実行します：

```bash

./scripts/build_image_trim_describer.sh

# Windowsの場合
./scripts/build_image_trim_describer.bat
```

go build -o bin/image-trim-describer ./cmd/cli/image-trim-describer
