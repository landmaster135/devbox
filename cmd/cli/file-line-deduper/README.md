# file-line-deduper

`file-line-deduper` は、指定されたファイルの各行から指定範囲の文字列を抽出し、その文字列が重複する行を削除するコマンドラインツールです。

## 概要

テキストファイル内の特定の列（文字位置）に基づいて重複行を検出し、それらを削除します。処理後、削除された行数を報告します。

## 使用方法

```bash
file-line-deduper -file <ファイルパス> -start <開始位置> -end <終了位置>
file-line-deduper -help
```

## オプション

- `-file` (string): 処理対象のファイルパスを指定します。（必須）
- `-start` (int): 各行から文字列を抽出する開始位置（0ベース）を指定します。（必須）
- `-end` (int): 各行から文字列を抽出する終了位置を指定します。（必須）
- `-help` (bool): 使い方を表示します。（任意）

## 使用例

ファイル `data.txt` の各行について、5文字目から10文字目までの文字列を比較し、重複する行を削除する場合：

```bash
file-line-deduper -file data.txt -start 5 -end 10
```
