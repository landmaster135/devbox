# ccusage-go

> **ccusage-go** - Claude Code usage analysis tool written in Go

A CLI tool for analyzing Claude Code usage from local JSONL files, inspired by the original TypeScript version [ccusage](https://github.com/ryoppippi/ccusage).

## Features

- 📊 **Daily Report**: View token usage and costs aggregated by date
- 💬 **Session Report**: View usage grouped by conversation sessions
- 📅 **Date Filtering**: Filter reports by date range using `--since` and `--until`
- 📁 **Custom Path**: Support for custom Claude data directory locations
- 🎨 **Beautiful Output**: Colorful table-formatted display
- 📄 **JSON Output**: Export data in structured JSON format with `--json`
- 💰 **Cost Tracking**: Shows costs in USD for each day/session
- 🔄 **Cache Token Support**: Tracks and displays cache creation and cache read tokens separately

## Installation

### Prerequisites

- Go 1.19 or later

### Build from Source

```bash
# Clone the repository
git clone https://github.com/your-username/ccusage-go.git
cd ccusage-go

# Build the binary
go build -o ccusage .

# Install globally (optional)
go install .
```

### Direct Run

```bash
# Run without installing
go run . daily

# Or build and run
go build -o ccusage . && ./ccusage daily
```

## Usage

### Daily Report (Default)

Shows token usage and costs aggregated by date:

```bash
# Show all daily usage
./ccusage daily
# or: ./ccusage

# Filter by date range
./ccusage daily --since 20250525 --until 20250530

# Use custom Claude data directory
./ccusage daily --path /custom/path/to/.claude

# Output in JSON format
./ccusage daily --json
```

### Session Report

Shows usage grouped by conversation sessions, sorted by cost:

```bash
# Show all sessions
./ccusage session

# Filter sessions by last activity date
./ccusage session --since 20250525

# Combine filters
./ccusage session --since 20250525 --until 20250530 --path /custom/path

# Output in JSON format
./ccusage session --json
```

### Options

All commands support the following options:

- `-s, --since <date>`: Filter from date (YYYYMMDD format)
- `-u, --until <date>`: Filter until date (YYYYMMDD format)  
- `-p, --path <path>`: Custom path to Claude data directory (default: `~/.claude`)
- `-j, --json`: Output results in JSON format instead of table
- `-h, --help`: Display help message
- `-v, --version`: Display version

## Architecture

The tool follows a clean architecture pattern:

1. **Data Loading** (`dataloader.go`) - Parses JSONL files from Claude's local storage
2. **Calculation** (`calculator.go`) - Aggregates token counts and costs by date or session
3. **Formatting** (`formatter.go`) - Handles table and JSON output formatting
4. **CLI** (`app.go`) - Command-line interface and argument parsing

## Limitations

- This tool only reads local JSONL files generated by Claude Code
- API usage for tools like Web Search, Code Execution, and Image Analysis are not included
- The tool only tracks language model token usage

## Requirements

- Claude Code usage history files (`~/.claude/projects/**/*.jsonl`)
- Go 1.19 or later

## Comparison with Original TypeScript Version

This Go implementation provides the same core functionality as the [original TypeScript ccusage tool](https://github.com/ryoppippi/ccusage) with these advantages:

- **Single Binary**: No need for Node.js runtime
- **Better Performance**: Faster execution for large datasets
- **Lower Memory Usage**: More efficient memory management
- **Easy Distribution**: Self-contained executable
