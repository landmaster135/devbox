### Improvements
- **memos (CLI)**: `list-memos` に `--any-contents` / `--all-contents` / `--any-tags` / `--all-tags` / `--excluded-tags` を追加し、本文・タグ条件を組み合わせた絞り込みをCLIだけで完結できるようにした。

### Refactor
- **memos (CLI)**: 本文検索オプションを `contents` から `any-contents` へ統一し、挙動を明確化した。
- **memos tests**: `list-memos` のテストを operation 単位で分割し、ケース追加時の保守性を改善した。

### Bug Fixes
- **memos-utility (CLI)**: `create-clips` のファイル名バリデーションエラーを改善し、無効名の原因が分かるガイダンスを追加して調査時間を短縮した。
- **filesystem MCP config**: Linux設定の `read_file` 承認モードを修正し、読み取り系操作で不要な承認待ちが発生しにくい状態にした。

### Documentation
- エージェントハーネス関連ドキュメントを更新し、運用時の参照導線を整理した。
- 廃止済みの movie/web clipping summary skill ドキュメント参照を削除し、現行構成との整合性を確保した。
