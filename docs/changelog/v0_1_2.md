### Improvements
- **image conversion Taskfile**: `cwebp` 変換タスクを追加し、Taskfile から画像変換フローを実行しやすくした。
- **Forgejo (CLI)**: 認証情報の読み込みを環境変数に統一し、設定ファイル依存を減らして実行環境ごとの切り替えを簡潔にした。
- **GitHub (CLI)**: GitHub CLI token を環境変数から読み込むようにし、秘密情報管理の扱いを整理した。
- **Codex hooks**: 一時出力ポリシーの guard hook を追加し、Go テスト出力や一時キャッシュ指定がプロジェクト方針から外れにくいようにした。

### Refactor
- **env-loader**: 廃止済みCLIと内部実装を削除し、環境変数読み込み責務を利用側へ集約した。

### Bug Fixes
- **Codex hooks**: temporary path guard の対象をGo環境に限定し、Goテストの compile output が `agent-work` 配下に収まるよう制約を修正した。
- **notion-to-memos-markdown (CLI)**: task backup tag suffix を `202602-notion` に統一し、docs とテストの期待値ずれを解消した。

### Documentation
- **hooks-craftsman skill**: Codex hook の作成・検証手順を扱う skill を追加し、hook 設定作業の参照導線を整備した。
- **go-version-update skill**: Go バージョン更新時の安全な手順、競合対応、検証観点をまとめた skill を追加した。
- **Taskfile docs**: image conversion namespace の確認手順を追記し、Taskfile追加時の衝突確認を明確化した。
