### Improvements
- **cron-workflow (CLI/HTTP)**: Memos本番DBダンプの定期運用を追加し、`pg_dump` クライアント更新・バイナリダンプ・リトライ対応でバックアップ信頼性を向上。
- **image-renamer (CLI)**: `extensions` フラグとprefix省略リネームを追加し、既存ファイル整理フローの適用範囲を拡大。
- **taskfile (CLI)**: `build-zip-tools` と `by-2-digits-image-rename-and-webp-convert` 系タスクを追加し、成果物配布と画像整形の自動化を強化。
- **memos (CLI)**: `update-tag` を有界並列化し、大量メモ更新時の処理時間を短縮。
- **color-code-converter (CLI)**: 10進カラー入力を追加し、色指定フォーマットの互換性を拡張。

### Refactor
- **file-line-deduper (CLI)**: 旧 `file-processor` から改名し、CLI設定パーサーとサービス層分離を進めて保守性を改善。
- **arithmetic-calculator (CLI/MCP)**: operation/service分割とCLIディスパッチ整理を行い、テスト粒度と責務境界を明確化。
- **skills/prompts**: 実装系プロンプトをSKILLファイルへ移行し、重複テンプレートを削除して運用を一本化。

### Bug Fixes
- **ci-workflow**: Go統合テストのログ出力を標準化し、失敗要約・コンテキスト表示・Docker実行差分吸収でデバッグしやすさを改善。
- **coverage-pipeline**: レポート出力先とバッジ入力の不整合を修正し、CI上でのカバレッジ更新失敗を抑制。
- **task markdown generation**: リネーム衝突、見出し分割、front matter再加工時の不整合を修正し、生成物の破損を防止。
- **build/config**: `golang.org/x/sync` を直接依存へ昇格し、MCP Linux設定で `get_git_diff` 承認ツールを有効化して実行安定性を改善。

### Documentation
- `AGENTS.md` の意思決定ツリーと導線を更新し、`docs/` マップへの参照性を改善。
- `docs/tool_implementation/` にTask実装ガイド、ポータブルパス規約、テスト移行ルールを追加。
- `docs/project_status/` に責務インデックスとユーザープロンプト導線を追加し、状況確認の入口を整理。
- `README` 群（`gcloud-genset-compute` / `memos-utility` / `scripts/ops/ci` など）を更新し、実運用手順と制約説明を明確化。
- スキル文書（web/movie clipping、git-commit-message generator、harness craftsman など）の要件とチェックリストを更新。
