# Changelog v0.1.3

## v0.1.3 — 2026-07-16

PR: pending

### Improvements
- **image-converter Taskfile**: WebP 品質値を対話入力できるようにし、PNG/JPEG 変換タスクから品質調整を扱いやすくした。
- **image-rename Taskfile**: screenshot rename タスクを package Taskfile に追加し、スクリーンショット名の整理を共通タスクから実行できるようにした。
- **Taskfile editor support**: Zed 用 Taskfile schema 設定を追加し、Taskfile 編集時の補完・検証を使いやすくした。
- **cron-workflow**: PostgreSQL cron backup を attachments data と extra tables dump に分割し、用途別の SQL ダンプを独立したワークフローとして扱えるようにした。
- **cron-workflow (Docker)**: HTTP runtime 用の Docker image に `lm-sensors` を追加し、CPU 温度チェックに必要な実行時依存を同梱した。 `.env.example` と compose sample を整備し、cron / HTTP イメージのパッケージングフローを簡素化した。

### Refactor
- **image-converter (CLI)**: directory 系フラグ名を整理し、CLI、Taskfile、build script、テストで同じ語彙を使うようにした。

### Bug Fixes
- **HTTP server packaging**: HTTP server のポート指定を `CRON_URL_PORT` に合わせ、Docker build から `env.yml` 依存を外して環境差分に強くした。
- **docker-compose sample**: CPU 情報収集に必要なホストシステムパスを公開し、compose sample での実行時診断が失敗しにくいようにした。
- **image-converter (CLI/Taskfile)**: 出力ディレクトリ必須化、archive-dir フラグ名、archive destination、original file copy/move の条件を揃え、変換後ファイルと元画像の退避挙動を安定化した。
- **image-trimmer (CLI/Taskfile)**: 出力ディレクトリ必須化と directory フラグ名を CLI、Taskfile、build script、テストで統一した。
- **pdf-merger (CLI/Taskfile)**: PDF 生成の出力先指定、画像探索の recursive オプション、明示的な operation 指定、`src-dir` / `src-file` / receiving file などのフラグ名と内部 option 名を揃え、CLI と Taskfile 経由の入力指定が期待どおり動くようにした。
- **image-synthesize Taskfile**: WebP 変換で不要な archive directory 指定を無効化し、合成用変換タスクが元画像を意図せず退避しないようにした。

### Documentation
- **cron-workflow README**: cron schedule と PostgreSQL env の重複説明を削り、ワークフロー説明を実装に近い内容へ整理した。
- **image-converter README**: 不要・重複した注意書きを削り、現在の CLI フラグと Taskfile 利用に合う説明へ更新した。
- **image-trimmer README**: usage 例と不要な記述を整理し、出力ディレクトリ指定を前提にした説明へ更新した。
- **AGENTS docs map**: project overview の参照リンクを実在するドキュメントに合わせて修正した。
