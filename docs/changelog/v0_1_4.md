# Changelog v0.1.4

## v0.1.4 — 2026-10-16
PR: pending

### Features
- **Goose 記事要約レシピ**: URL と出力ディレクトリを指定し、記事取得から日本語要約 Markdown の作成まで実行するレシピを追加した。HTTP request / web-clipper MCP と記事・動画クリッピング用スキルを組み合わせ、親レシピからサブレシピへ処理を渡す構成を整備した。スキル読み込みだけで終了せず、ファイル作成まで続行する指示とツール設定も追加した。
- **Goose 開発支援レシピ**: Goose の設定とコード解析・タスク自動化用レシピを追加し、Ollama を使ったコード構造の調査や UI 試作のための構成を用意した。

### Improvements
- **image-converter-by-libwebp (CLI/Taskfile)**: WebP の圧縮メソッドを `--m` で指定できるようにした。指定範囲は `0`〜`6`、既定値は `4` とし、画像変換 Taskfile では `--m=6` を使用するようにした。
- **Codex 設定**: リポジトリ内の Linux 向け設定でモデルを `gpt-5.5` に変更し、承認ポリシーを `on-request`、サンドボックスを `workspace-write` として明示した。一時ディレクトリの扱いも設定し、フック有効化キーを `codex_hooks` から `hooks` に更新した。

### Refactor
- **エージェント作業領域**: 一時成果物の保存先を `.agents` 配下から `agent-work` 配下へ移行した。Go テスト出力のガード、Taskfile、Git / Docker の除外設定、関連スキルとドキュメントの参照先を揃えた。

### Documentation
- **Goose 検証レシピ**: web-clipper の Markdown 更新を単体・サブレシピ経由で確認する検証用レシピと、実行・デバッグコマンドを追加した。
- **docker-healthcheck skill**: Dockerfile / compose.yaml を対象に、コンテナのヘルスチェックを設計・実装する手順を追加した。
- **Go 開発スキル**: 関数の設計方針を簡潔さと可読性の優先へ更新し、テストファイル名を対象ファイル名に対応させる命名規則を明記した。
- **PR 作成スキル**: 確認事項を一度にまとめて提示する手順へ更新し、重複する PR タイトル例を削除した。
- **postgres-table-design skill**: 別リポジトリへの移管に伴い、このリポジトリ内のスキルを削除した。
