# docs 管理ガイド

このドキュメントは、`docs/` 配下の配置方針と目次（マップ）管理を定義します。

## AGENTSマップのリンク整合性

1. `AGENTS.md` に記載したドキュメントパスが実在することを確認する
2. `docs/` に新規ドキュメントを追加した場合は、`AGENTS.md` の docs マップにリンクと用途を追記する
3. ドキュメント移動・リネーム時は、`AGENTS.md` と関連ドキュメント内の参照パスを同時に更新する

## 最小チェック

- `AGENTS.md` の参照リンクがすべて有効
- 新規追加ドキュメントが docs マップに反映済み
- 旧パス参照が残っていない
